Legend

Arrows — what the relationship is

  • constrains — authority flows down — the target must satisfy the source
  • sequences — defines the order the target runs in
  • enforces — blocks the merge when the standard is violated
  • produces — fills in / emits the target
  • explains — documents, binds nothing
  • delegates — hands the work to a vendor we do not own
  • validates — proves it before it ships downstream

Pill — how the file reaches a project

  • inhinherited — raw URL, live at the next session start; you do nothing
  • insinstalled — plugin, lands next session via the SessionStart hook (legacy projects without it: on the environment cache rebuild, ~weekly)
  • copcopied — snapshot taken at bootstrap; resync with /refresh-repo
  • refreferenced — read on demand, nothing stored downstream
  • intinternal — never leaves this repo

Glyph — whether it may be replaced

  • 🔒permanent — evolves by PR, never wholesale-replaced
  • ★orchestrator — also defines the interfaces its components fit
  • 🔌vendor socket — the wiring for something we do not own
  • —no glyph — swappable within its compartment's interface
