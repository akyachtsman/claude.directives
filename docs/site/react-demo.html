Browser-only React preview

The button below is a real, stateful React component running in your browser — no build, no terminal. This is the production-tier preview technique: the same component drops into a Next.js app verbatim, where Vercel's next build compiles it for real.

Loading the React preview…

You author it as JSX:

function LikeButton() {
  const [n, setN] = React.useState(0);
  return <button className="btn" onClick={() => setN(n + 1)}>♥ {n}</button>;
}

A compiler turns that JSX into React.createElement(...) calls — Babel does it in a live browser preview, Vercel's next build does it for production. This page ships the compiled output below so it stays lean and dependency-free.
